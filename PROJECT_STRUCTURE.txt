[EN] Description
--------------------------------------------------------------------------------
core/
    C++ core logic, compiled into a dynamic library.
    Windows: core.dll        Linux: libcore.so
    Exported interfaces are only those marked with EXPORT.

frontend-fltk/
    C++ frontend built with FLTK.
    Links directly against the core library.

frontend-tk/
    Python frontend built with TKinter.
    Loads the core library via ctypes.

.gitignore
    Ignores build artifacts (*.dll, *.so, *.o, __pycache__, build/, etc.).

LICENSE
    License of this project (MIT by default).

README.md
    Project overview, build and usage instructions.
